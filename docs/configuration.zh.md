# 配置协议

[English](configuration.md)

版本 1 接受 `version`、`workingDirectory`、`installCommand`、`startCommand`、`port`，以及 `healthcheck` 中的 `path`、`timeoutSeconds`。安装命令包含所需构建步骤。服务必须以前台方式运行，并监听可访问接口，通常为 `0.0.0.0`。

仅接受单个 UTF-8 YAML 文档，最大 64 KiB。拒绝未知或重复字段、别名／合并、过深嵌套、非法端口、逃逸路径和不安全的健康检查路径。工作目录默认为 `.`，检查路径默认为 `/`，检查时限默认为 60 秒。显式非正时限会被拒绝；执行时最多等待 300 秒。配置路径由调用方选择，库不规定特定产品的文件名。

凭证不得写入版本化配置或命令。运行时环境变量是独立于不可变源码证据的临时输入。
