# 实时输出与服务日志

[English](logs.md)

## 执行输出

`Options.OnOutput` 保留阶段结束输出语义；可选 `OnLiveOutput` 在安装或启动输出到达时发送，无需等待阶段结束。两者对传入字面值和临时 `Options.Env` 值脱敏，stdout 与 stderr 合计每阶段最多 64 KiB 原始输入，事件为最多 4 KiB 的有效 UTF-8。同时启用时会收到同一输出的两种视图，不能将其作为不同记录重复持久化。Git 适配器目前在检出结束后才释放输出，先完成其自身凭证脱敏。

实时脱敏延迟保留最长秘密值长度减一的后缀，以及不完整 UTF-8 字节，避免秘密跨传输块泄露并保留重叠掩码。很长的秘密值可能使输出延迟到结束。观察结束时会保守隐藏可能构成凭证开头的不完整后缀。两个流的后缀独立确定，因此不保证 stdout 与 stderr 的精确交错顺序。脱敏不识别变换后的秘密或终端标记。

回调同步执行，在各自输出订阅内串行化，必须及时返回且不得重新进入运行时 API。应用负责有界队列、纯文本渲染、存储、时间戳、关联标识与背压。

## 服务观察

`LogSource` 是可选能力，必需的 `Runtime` 接口保持不变。envd 适配器通过 Process `Connect` 合同实现：先用 `List` 核对运行时、PID 与标签，再选择唯一标签，收到匹配 PID 确认后才发送输出。观察路径不发送进程信号。内置 local 适配器不提供历史或可重连的服务日志。

使用 `FollowLogs`，不要直接转发原始 `LogSource.Logs` 输出。订阅使用调用方的取消或期限，原始输入最多 64 KiB，可用 `LogOptions.MaxBytes` 降低。将 agent 令牌和应用秘密加入 `Redact`；重新附着的订阅没有 Apply 的临时应用环境，无法自动推导这些值。事件的 `Stage` 为空，因为服务可能独立于部署阶段持续运行。参见[可编译示例](../logs_example_test.go)。

超过预算会发送一次截断标记，并返回 `ErrLogLimit`。取消或关闭订阅**只结束观察**；终止工作负载须由控制器另行调用 `Stop`。provider 失败通过可安全打印的 `LogError` 保留 `errors.Is` 身份；正常观测到进程退出会成功结束采集，生命周期状态需单独核对。

agent 的缓冲、重放、保留和游标由 provider 定义，不保证无缺口或恰好一次记录。盲目重连可能重复输出。日志持久化、重放策略和 SSE 由控制器负责。真实 agent 兼容性仍须通过显式启用的[远程验收](envd-acceptance.zh.md)确认。
